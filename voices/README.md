# Quizman Voices

Отдельный Android TTS-движок на Supertonic 3. Минимальная версия: десять встроенных голосов, русский язык, пробный текст, скорость и остановка. Работает на телефоне и Android TV, с пультом или сенсорным экраном. Android 8.0+; ARM64, ARMv7, x86 и x86_64.

## Использование

1. Установить `Quizman-Voices-debug.apk` на то же устройство, где работает Квизман.
2. Открыть Quizman Voices и нажать «Прослушать». Модель уже внутри APK; сеть не нужна.
3. В настройках озвучки Квизмана выбрать движок `Quizman Voices · Supertonic`, затем голос `Supertonic-M1-ru-RU` … `Supertonic-F5-ru-RU`.
4. При необходимости обновить Квизман APK из той же сборки: в нём добавлена видимость TTS-сервисов для Android 11+.

Не обязательно менять системный движок по умолчанию: Квизман выбирает его явно. Выбранный в менеджере голос используется как голос по умолчанию при запросе русского языка; явный выбор в игре имеет приоритет. Скорость на экране относится к прослушиванию; игра задаёт собственную скорость.

APK для разработки подписан debug-ключом. Данные игры сохраняются при обычном обновлении с тем же ключом; не удаляйте игру ради установки. Для публикации понадобится релизная подпись.

## Реализация

- `SupertonicService`: стандартный Android `TextToSpeechService`; 10 локальных `Voice` с локалью ru-RU.
- sherpa-onnx 1.13.8 AAR и Supertonic 3 INT8 (2026-05-11), inference на CPU, 2 потока, 5 шагов.
- Модель читается из assets. Загрузка происходит при первом запросе вне UI-потока; затем модель остаётся в памяти связанного сервиса.
- PCM 16-bit mono 44100 Hz возвращается Android через `SynthesisCallback`; воспроизведением управляет Android.
- Длинный текст разбивается на небольшие фрагменты. Stop прекращает отправку звука; текущий нативный шаг может закончиться прежде, чем начнётся следующая реплика.
- Выключение экрана менеджера не отключает движок для других приложений. Нет постоянно запущенного foreground-сервиса.
- Высота тона в этой версии не меняется. Клонирования и импорта пользовательских JSON нет.
- Поддерживаемый язык первой версии — русский. Остальные языки модели не объявляются Android.

## Сборка и проверки

Из корня репозитория (JDK 17+, Android SDK 35):

```powershell
./gradlew.bat :voices:assembleDebug :voices:testDebugUnitTest :voices:lintDebug :tv:assembleDebug
./gradlew.bat :voices:connectedDebugAndroidTest
```

APK: `voices/build/outputs/apk/debug/voices-debug.apk`.
Тесты Android проверяют обнаружение 10 голосов, русский язык, WAV мужского и женского голосов, остановку и следующий запрос. Unit-тесты проверяют разбиение текста, UTF-16 и PCM. Тестовые WAV остаются в cache приложения на эмуляторе.
