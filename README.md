# Dr. Quizman — compact one-screen landing

## Что изменено
- макет стал компактнее;
- фон теперь внутри карточки, а не "на весь экран";
- ведущий оставлен исходный;
- главная кнопка ведёт на скачивание APK.

## APK
Положите файл в корень сайта и назовите:

`DrQuizman.apk`

Если имя будет другим, замените `DrQuizman.apk` в `index.html`.

## GitHub Pages
Загрузите все файлы из архива в репозиторий и включите:
Settings → Pages → Deploy from a branch → main → /(root)
