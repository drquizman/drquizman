## APK

`DrQuizman.apk`

Если имя будет другим, замените `DrQuizman.apk` в `index.html`.

## GitHub Pages
Загрузите все файлы из архива в репозиторий и включите:
Settings → Pages → Deploy from a branch → main → /(root)

## Запуск веб-версии

Кнопка на главной ведёт на `/web/`. Статическая страница остаётся на GitHub Pages: показывает подготовку, проверяет публичный `/health` на Render и после ответа `ok` загружает игру в iframe. Адрес сайта сохраняется; DNS менять не нужно. Комнаты и WebSocket обслуживаются Render. QR и ссылки студии ведут на `https://www.drquizman.ru/web/remote/?pin=…`: страница пульта сохраняет наш адрес, проверяет готовность и открывает соответствующий пульт Render в рамке. Без PIN доступен ручной ввод кода комнаты.

Запросы выполняются только во время подготовки (до 150 секунд) и прекращаются после готовности/ухода со страницы. Есть повторная попытка и прямое открытие игры при ограничениях встроенных окон или хранилища браузера. Рамке разрешены полный экран и воспроизведение аудио; нижняя панель не перекрывает игровую область. `node check-launch.mjs` проверяет готовность, повторы, тайм-ауты, повторный запуск и отмену.
