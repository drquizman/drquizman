# Dr. Quizman

Упрощённая 2D-телевикторина: телевизор — студия, пульт — страница в браузере телефона.

## Как запустить

1. В Android Studio модуль **tv** → Run на эмулятор или телевизор.
2. На ТВ: **Играть**. На экране ссылка и PIN.
3. На телефоне (та же Wi‑Fi) откройте ссылку в браузере, введите имя → **Готов**.
4. Когда готовы все — игра начинается сама.

### Если ТВ крутится в эмуляторе на компьютере

В терминале:

```
adb forward tcp:17890 tcp:17890
```

Затем на компьютере или телефоне: [http://127.0.0.1:17890](http://127.0.0.1:17890)

## Модули

- `core` — движок и протокол
- `tv` — студия + веб-пульт (`assets/remote/index.html`)
