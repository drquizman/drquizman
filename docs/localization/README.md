# Локализация Dr. Quizman

Язык выбирается из списка в меню, сохраняется в настройках приложения и применяется при следующем запуске. Поддерживаются `ru`, `he`, `en`, `es` и `de`; устаревшее обозначение иврита `iw` нормализуется в `he`.

Немецкий набор подключён целиком: 2230 основных вопросов, 30 вопросов «Верю — не верю», 9 резервных вопросов, 149 ключей приложения, 56 ключей пульта и шесть файлов реплик. Источник — итоговые файлы из `quiz_german_localization`, без промежуточных `checkpoints`. В меню — Deutsch с флагом 🇩🇪; озвучка использует голоса локали `de`.

Испанский набор подключён целиком: 2230 основных вопросов, 30 вопросов «Верю — не верю», 9 резервных вопросов, 149 ключей приложения, 56 ключей пульта и шесть файлов реплик. Источник — итоговые файлы из `quiz_spanish_localization`, без промежуточных `checkpoints`. В меню — Español с флагом 🇪🇸; озвучка использует голоса локали `es`.

Английский набор подключён целиком: 2230 основных вопросов, 30 вопросов «Верю — не верю», 9 резервных вопросов, 149 ключей приложения, 56 ключей пульта и шесть файлов реплик. Источник — итоговые файлы из `quiz_english_localization`; промежуточные `checkpoints` не используются. Английские голоса фильтруются существующим механизмом по локали `en`.

## Файлы

- `tv/src/main/assets/questions/ru.json`, `he.json` — основные вопросы. Старый дубликат `assets/questions.json` удалён.
- `core/src/main/resources/locales/ru/true-false.json` — 30 вопросов «Верю — не верю». Для перевода создать соседний `he/true-false.json`.
- `core/src/main/resources/locales/ru/fallback-questions.json` — 10 резервных вопросов; перевод — `he/fallback-questions.json`.
- `core/src/main/resources/locales/ru/strings.json` — интерфейс, подсказки, служебные игровые реплики, названия и правила стартового, скоростного, финального раундов и «Верю — не верю». Перевод — `he/strings.json`.
- `core/src/main/resources/locales/ru/remote.json` — тексты веб-пульта. Перевод — `he/remote.json`.
- `core/src/main/kotlin/com/drquizman/core/i18n/ru/*LinesRu.kt` и `he/*LinesHe.kt` — уже подключённые реплики ведущего и пяти механик.

Если файла или ключа перевода нет, используется русский оригинал. Ивритские переводы подключены: все 146 ключей приложения, 56 ключей пульта, 30 вопросов «Верю — не верю», основная база и шесть файлов реплик. Резервная ивритская база содержит 9 вопросов: в присланном наборе отсутствует ID 9003 (вопрос про «Евгения Онегина»); русский вопрос вместо него не добавляется.

В JSON переводить только текстовые значения; ключи, ID, порядок ответов и `Correct_Answer_Index` не менять. Плейсхолдеры `{0}`, `{1}` сохранять; их можно переставлять. Для вопросов переводить `Question`, `Answers`, `Topic`. Папка `to-translate` содержит исходные заготовки уже выполненного перевода; приложение их не загружает. Рабочие переводы находятся в `locales/he`.

Направление интерфейса для иврита — RTL, веб-пульт получает язык и словарь от приложения. Смена языка пересоздаёт состояние меню, чтобы не оставались старые названия конкурсов.

## Голоса

Список голосов фильтруется по выбранному языку. После смены языка старый голос сбрасывается, предпочтение получает распознанный мужской голос, выбранное имя сохраняется. При запуске и смене TTS-движка применяется текущая локаль. Если пол не указан в имени голоса, гарантировать мужской тембр нельзя; выбирается доступный голос этой локали. Если движок не предоставляет голосов языка, список пуст и реплики не озвучиваются другим языком; игру можно продолжать. Голоса устанавливаются средствами соответствующего TTS-движка.

## Проверки

- `gradlew.bat :core:checkLocalization :tv:assembleDebug` — проверка переключения языков, ресурсов, fallback и сборка APK.
- `node tools/check-localization.cjs` — структура баз, плейсхолдеры переводов и отображение веб-пульта.
- `node tools/check-question-limits.cjs ru` — необязательный редакторский отчёт о длине вопроса свыше 110 символов и ответа свыше 50. Это отдельный старый инструмент подготовки текстов, не часть игры и не шаг Gradle. Он ничего не обрезает, не исключает вопросы и не меняет игровой процесс. Для иврита можно передать `he`.

## Добавление следующего языка

Добавить код в `LocaleManager`, словари и базы под этим кодом, реализации реплик с тем же публичным API и маршрутизацию в фасадах `HostLines` / `*Lines`. Список в диалоге «Язык» автоматически берёт коды из `supportedLanguages()` и отображает собственные названия языков. Текущий язык отмечен галочкой; закрытие диалога без выбора не меняет настройку. Одного файла вопросов недостаточно для полного перевода.
